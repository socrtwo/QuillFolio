# Roadmap

- **M0 — planning:** done. Command plan, formats plan, architecture plan, innovations survey, legal notes.
- **M1 — first working version:** done (0.1.0). The suite shell with every tab; the engine (parse, repair, edit, write, encrypt); the viewer; comments, forms, protection, Fill & Sign, page organization, OCR, review checks, tools, the AI tab; repair pipeline with report; builds for every platform; unit and smoke tests.
- **M2 — fidelity and depth:** annotation appearance options (line endings, dashes, fonts in text boxes), rich-text comments, caret and replace-text annotations, choice-field appearances with scrolling, comb fields, field validation and calculation (recorded, not executed as JavaScript), measurement perimeter and calibrated areas on the page, compare with side-by-side synchronized scrolling, print preview, rulers and grid.
- **M3 — engine:** JBIG2 and JPEG 2000 decoding in the engine (extraction and pixel redaction of those images), CID-font text editing in place, font subsetting and embedding for new text, linearization, conforming PDF/A-2b and PDF/UA output with color profiles, portfolio creation, tagging of new content.
- **M4 — signing and trust:** certificate-based signatures (PKCS#7/PAdES) with platform key stores, timestamps, signature validation with certificate chains, long-term validation data.
- **M5 — workflows:** shared review sessions through the sister apps, more batch operations, scanner integration where platforms allow it, page-rotation inference for scans, compare-as-you-type for forms.
